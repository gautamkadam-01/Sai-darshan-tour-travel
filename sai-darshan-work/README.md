# Sai Darshan Tour & Travel — MERN Website

## Design update
The latest redesign uses a light premium palette: ivory, forest green and warm saffron/gold. It focuses attention on service headings, one-way/round-trip enquiry, WhatsApp CTA and the vehicle fleet.

## Vehicle photos
The fleet cards currently use real-model reference images from public automotive/travel image URLs. For the final business website, replace these with the owner's own vehicle photos in `client/src/data/content.js` (or local files under `client/public/vehicles`) so the website represents the actual fleet.

No destination/location photos are used in the redesign.

## Run
```bash
cd client
npm install
npm run dev
```

For backend:
```bash
cd server
npm install
copy .env.example .env
npm run dev
```
